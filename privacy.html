Privacy Policy

Last updated: 11 November 2026

Root Cause Uploader is a private tool used only by the owner of the Root Cause YouTube channel to upload videos and manage playlists on that channel.

Data we access

With the channel owner's permission, the tool uses the YouTube Data API to upload videos, set their titles, descriptions and publishing schedule, and add them to the channel's playlists.

Data we store

The OAuth token is stored only on the owner's own machines and is never shared. The tool does not collect, store or share data about any other user.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. See also the Google Privacy Policy.
